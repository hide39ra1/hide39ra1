## 技術開発・研究活動

### 室内飛行ロボット
2026年の室内飛行ロボットコンテストに向けて、機体製作、オープンソースの飛行制御ソフトウェアを活用したプログラミング、飛行制御の設定・調整、飛行試験を担当。出場チームはビギナー部門で準優勝。

### 画像認識による蚊の幼虫検出
YOLOによる微小物体検出について、学習データ量や、ダミー・実幼虫の利用が検出に与える影響などを検証。

### UWBを用いた転倒検知
UWBセンサーデータと時系列解析による転倒検知手法の評価。
