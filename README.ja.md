## 技術開発・研究活動

### 室内飛行ロボット
2026年の室内飛行ロボットコンテストに向けて、機体製作とプログラミングを担当。出場チームはビギナー部門で準優勝。

### 画像認識による蚊の幼虫検出
YOLOによる微小物体検出について、学習データ量や、ダミー・実幼虫の利用が検出に与える影響などを検証。

### 野生動物検出・通知システム
TensorFlow.jsを使ったブラウザ上の野生動物検出と、Google Apps Scriptを組み合わせた通知機能の開発。

### UWBを用いた転倒検知
UWBセンサーデータと時系列解析による転倒検知手法の評価。
