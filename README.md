## Engineering & Research Projects

### Indoor Flying Robot
Contributed to aircraft construction, programming based on open-source flight-control software, flight-control configuration and tuning, and flight testing for the 2026 indoor flying robot contest. The team finished as runner-up in the Beginner Division.

### Mosquito Larvae Detection with Computer Vision
Investigating small-object detection with YOLO, including the effects of training-data volume and the use of physical models and real specimens.

### UWB-Based Fall Detection
Evaluating fall-detection approaches using UWB sensor measurements and time-series analysis.
